# Sentinel India 2026: Design System

## 1. Visual Identity: "Cyber-Civic"
The aesthetic combines governmental authority with a modern high-tech dark mode.

## 2. Color Palette
* **Surface/Background:** `#0F172A` (Deep Navy)
* **Action Primary:** `#10B981` (Sentinel Green)
* **Information:** `#38BDF8` (Sky Blue)
* **Warning:** `#FACC15` (Yellow)
* **Error:** `#FB7185` (Rose)

## 3. Typography
* **Headings:** Inter/Segoe UI Bold
* **Body:** Segoe UI Regular
* **Metrics:** Roboto Bold (High contrast)

## 4. Components
* **Cards:** 12px rounded corners, 1px solid border.
* **Buttons:** 8px border radius, high-contrast labels.
